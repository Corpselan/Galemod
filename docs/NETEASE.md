# 网易云音乐和 3D 歌词

两个模块：

- **NetEase Music**（客户端分类）：网易云音乐播放器，**声音从游戏里出来**（和 Spotify 不一样，Spotify 只能遥控）。命令 `/netease`（也可以 `/ne`、`/wyy`）。
- **Lyrics**（渲染分类）：3D 歌词。网易云或 Spotify 正在放的歌，歌词一句句浮在面前，唱到哪个字哪个字弹出来，带泛光。照着 DangoMusic 的实时 3D 歌词做的。

两个播放器的界面左上角都有一个小按钮（「网易云」/「Spotify」），点一下切到另一个。

## 网易云音乐

打开模块，输入 `/netease gui`（或者设一个 Player key）。

- **不登录**也能：搜歌、看推荐歌单和排行榜、听免费的歌；
- **登录**以后：我的歌单（包括「我喜欢的音乐」），VIP 账号能听 VIP 歌曲。

**登录**：播放器里点「我的歌单」，或者 `/netease login`，会出现二维码，用网易云音乐 App 扫一扫，在手机上确认。登录信息存在 `.minecraft/galemod/netease.json`（只在你电脑上，只发给网易云），`/netease logout` 删掉它。扫码不方便时，也可以在浏览器登录 music.163.com，把 Cookie 里 `MUSIC_U` 的值用 `/netease cookie <值>` 填进来。

**播放器**：

- 左边：正在播放、推荐歌单、我的歌单、排行榜、搜索，下面是你的歌单；
- 中间：歌的列表。**左键**从这首开始放这个列表，**右键**设成下一首播放。标着 `VIP` 的要 VIP，灰色标着 `无版权` 的是网易云说这个账号（或这个地区）放不了的；
- 「正在播放」里，Lyrics 模块开着时会显示当前的几句歌词（唱到的那句是红的），没开就显示播放列表；
- 下面：随机、上一首、播放/暂停、下一首、循环（列表 → 单曲 → 关），拖进度条、拖音量条；右上角是音质；
- 键盘：空格播放/暂停，← → 前后 10 秒，↑ ↓ 音量。

**设置**：Volume（音量）、Quality（128k / 192k / 320k，320k 大多要 VIP）、HUD（屏幕上的卡片，打开聊天框可以拖动和缩放）、Hide when paused、Song notifications、几个按键（Player、Play/Pause、Next、Previous、Volume up/down，填键名，`NONE` 不绑）。

**屏幕上的卡片**：和 Spotify 的一样，网易云红色；右上角的小条跟着歌的鼓点跳。

**命令**：

| 命令 | 作用 |
|---|---|
| `/netease gui` | 打开播放器 |
| `/netease play 晴天` | 搜一下，从第一首开始放 |
| `/netease search 晴天` | 打开播放器搜索 |
| `/netease login` / `logout` | 扫码登录 / 退出 |
| `/netease cookie <MUSIC_U>` | 用浏览器里的登录 cookie 登录 |
| `/netease status` | 现在放的是什么 |
| `/netease p` / `pause` / `resume` | 播放暂停 |
| `/netease n` / `prev` | 下一首 / 上一首 |
| `/netease vol 30`、`vol +10` | 音量 |
| `/netease seek 1:30` | 跳到 1 分 30 秒 |
| `/netease shuffle` / `repeat` / `stop` | 随机 / 循环 / 停止 |

**放不了的歌**：网易云会说哪些歌这个账号放不了（没版权、要 VIP，或者你所在的地区没有版权），这些歌会直接跳过；一个列表里全都放不了时会停下来告诉你。只能试听的 VIP 歌会放 30 秒片段（右上角显示「试听」）。

**怎么放的**：整首歌先下载到内存（128k 一首大约 4 MB），然后在后台一帧一帧解码（JLayer）写给声卡；解码时顺便听低音的突然变强，当作鼓点，给歌词和卡片用。所有网络请求都在后台线程，不卡游戏。用的是网易云网页版和 PC 客户端的接口（和 DangoMusic 一样）。

## 3D 歌词（Lyrics）

打开 Lyrics 模块，再放歌（网易云或 Spotify）就行。

**歌词从哪来**：

- 网易云的歌：按歌的 id 直接拿，有逐字时间（YRC）的用逐字的，没有就用逐行的（LRC）；
- Spotify 的歌：Spotify 不给歌词，按歌名、歌手、时长去找：中日韩的歌先找网易云（搜索，挑时长差 3 秒以内的那首），其它先找 [LRCLIB](https://lrclib.net)（开放的歌词库），找不到再找另一个。「Spotify lyrics」可以固定只用一个；
- 「作词：」「作曲：」这种行，「纯音乐，请欣赏」都会去掉；网易云常把两句写成一行（中间一个空格），会拆开分别出现（Split lines）。

**样子**：每句歌词出现在你视线方向前面 10 格左右（Distance）、往上一点、左右随机偏一点（Spread），字一个个弹出来（Word pop：有逐字时间的歌按真实时间，没有的按这句的长度均匀分），每个字低帧率轻轻抖（Wiggle，像手绘动画），下一句来时上一句往上飘着淡出。歌暂停时歌词淡出，继续时淡回来。

- **Glow**：Deep Glow 泛光，中间白热、外圈一大片柔光。Glow color（跟文字一样 / 粉 / 蓝 / 金）、Glow strength、Glow radius；
- **Smooth font**：清晰字体，用你电脑里的微软雅黑等画，中文也清楚；关掉用 MC 的像素字；
- **Face player**：歌词一直转过来面对你；**Keep away**：走近时往后退；**Stay on screen**：转头时歌词滑回视野里；
- **Color**：文字颜色；**Scale**：大小；
- **Offset**：歌词早了往负调、晚了往正调。Spotify 的进度是隔几秒问一次再在本地推算的，有网络延迟，常要 +100～+300ms；
- **Follow**：跟哪个播放器（Auto：正在放的那个，两个都在放时先网易云）；
- **Style → Text flash**：另一种样子，大号粗体的词一个个砸到屏幕中间，随机红色或白色，偶尔一个词单独斜着砸进来；网易云的歌会跟着鼓点放大和抖动（Spotify 拿不到声音，所以没有鼓点）。

**画在哪**：世界画完之后（RenderWorldLast），不受方块遮挡；泛光是把歌词单独画一遍，缩小七次再一级级加回来，最后按曝光曲线叠到屏幕上（显卡不支持帧缓冲或着色器时自动关掉泛光，不影响歌词）。画完把 GL 状态原样放回去。

## 自测

- `gradlew neteaseCoreTest`：不开游戏。离线部分测加密（weapi）、LRC 和 YRC、拆行、纯音乐、歌名匹配、二维码、歌曲解析；联网部分测网易云搜索、歌词（含逐字）、排行榜、推荐歌单、加密请求被网易云接受、按歌名找 Spotify 歌的歌词、LRCLIB，以及静音放一首免费歌（进度、鼓点、暂停、跳转、下一首）。
- `gradlew runClient -Plyricstest`：游戏里。一首假歌（中英文歌词）测 3D 歌词、泛光、清晰字体、换行、暂停和继续、GL 状态、像素字、粉色泛光、留在屏幕里、Text flash；然后联网静音放一首真的网易云歌，歌词跟着出来；播放器的推荐歌单、排行榜、搜索、扫码登录，和两个播放器之间切换。截图在 `run/screenshots/lyrics-*.png`。
