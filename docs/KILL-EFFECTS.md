# Champions 2021 / 2023 / 2024 与 end 击杀特效

在右 Ctrl 设置界面的 **渲染 / Render** 分类打开 **KillEffects**，或者输入：

```text
/gale KillEffects
```

首次打开时只预载当前年份的六张贴图。默认图标位于屏幕横向 50%、纵向 66%，在准星下方，避免挡住战斗视野。在 Theme 中选择 2021、2023 或 2024，图标和音效会一起切换；选择同级的 `end` 则在敌人死亡位置播放参考视频的透明红叶白树动画。原有配置继续使用 2021。

切换到 2024 并预览：

```text
/gale set KillEffects Theme 2024
/gale killfx preview all
```

切换年份保留实际连杀数，同时停止旧年份的声音、图标和剩余预览，避免两套效果混在一起。

## end 视频风格击杀树

```text
/gale set KillEffects Theme end
/gale killfx preview 1
```

以用户提供的 `1018.mp4` 为外观参考，使用透明动画贴片保留银白色尖脊枝干、红色空腔和深红叶簇。按用户选择，树围绕脚底的竖直轴始终朝向相机；这是世界坐标中的相机朝向贴片，不是可绕行查看不同侧面的三维树模型，也不是屏幕 HUD。

动画由三张独立透明素材组成：萌芽、半长成和成熟树。阶段间缩放生长并交叉淡化，约 2.7 秒长成；外围另绘制旋涡、落叶和地面光雾。素材是内置 ImageGen 根据用户视频帧重建，非原片逐帧无损抠图，也不包含原游戏导出的模型；细节仍可能与原视频不同。

- 每次确认击杀，保存受害者脚底的死亡坐标；贴片转向时脚底位置保持不变，不跟随尸体或玩家移动。
- 保留世界深度测试，会被墙和场景遮挡。最多同时保留四棵树，超过上限淘汰最早生成的树；96 格外不绘制。
- `Tree size`：默认 1，成熟树约 8 格高，范围 0.5～2。
- `Tree lifetime`：默认 8 秒，范围 3～16 秒，包含生长和最后 0.7 秒淡出。短于完整生长时长时会加快生长。
- 每张图片按实际透明轮廓测量脚底中心，用同一死亡坐标对齐，避免切换素材时底部滑动。
- 不使用 HUD 的 Size / X / Y / Duration，不播放 Champions 音效。
- 自己死亡、换世界、关闭模块和手动 reset 都会清除；切换主题保留真实连杀数。
- `preview 1` / `preview all` 都在面前约 5 格的地面生成一棵完整预览，不改变实际连杀。
- 三张素材只在开启/切换到 end 时预载，绘制时不解码图片、视频或重建纹理；使用原版纹理缓存，空闲时不绘制。

Server 模式在死亡包到来时记录位置，等待击杀公告确认后才生成。只有公告而缺少已知受害者坐标时仍计连杀，但不猜位置生成树。原有识别范围和去重规则与 Champions 相同。

## Champions 效果

- 使用提供的 Champions 2021 / 2023 / 2024 素材，每年各六级图标和六段音效。图标按各年的原始素材保留，2024 高连杀的光晕也直接来自贴图。
- 首次触发从 42% 大小放大到正常大小，使用 ease-out-back 缓动，带轻微回弹；动画按实际时间推进，高低 FPS 下时长一致。
- 1→2→3→4→5→6 杀使用约 180 ms 的缩放和透明度过渡；连续触发可以中断当前过渡，始终最多两层贴图。
- 约 280 ms 后大小稳定，默认总显示时间 2.2 秒，末尾淡出。
- 六杀以后继续播放第六级；自己死亡、重生、进入/离开世界和关闭模块会清零并停止自己的音效。
- 默认不因时间间隔清零；可通过 Reset after 设置自动清零时间。
- 新音效替换上一段音效，同一 tick 的快速连杀合并为最终一级，至多延后一个 tick（通常 50 ms），避免叠音及旧版 OpenAL 通道竞争。受游戏主音量和模块 Volume 控制。

## 预览和重置

```text
/gale killfx preview all
/gale killfx preview 1
/gale killfx preview 6
/gale killfx reset
```

预览会开启模块，仅本地播放，不向服务器发包，也不改变实际连杀计数。`all` 每隔 0.75 秒播放下一级，方便观察升级过渡；真实击杀发生时会中止剩余预览。

## 设置

| 设置 | 默认值 | 作用 |
|---|---|---|
| Theme | 2021 | 2021 / 2023 / 2024 图标音效，或 end 世界树 |
| Tree size | 1 | end 树的比例，0.5～2 |
| Tree lifetime | 8 s | end 动画总时长，3～16 秒 |
| Sound | 开 | 对应等级的音效 |
| Volume | 0.7 | 模块音量，0～1 |
| Size | 96 | 完整 300×300 图片绘制到多少 GUI 像素 |
| X / Y | 50% / 66% | 相对屏幕的位置 |
| Duration | 2.2 s | 图标一次显示的总时长 |
| Reset after | 0 s | 0 表示关闭超时重置；死亡和换世界仍会重置 |
| Players only | 开 | 关闭后也会对生物触发，盔甲架除外 |
| Detection | Auto | 击杀识别方式，见下文 |

例如：

```text
/gale set KillEffects Volume 0.5
/gale set KillEffects Size 160
/gale set KillEffects Y 70
/gale set KillEffects ResetAfter 20
/gale set KillEffects Detection Server
```

## 击杀识别的范围

`Auto` 跟踪你最近八秒攻击过的目标，收到目标死亡状态或检测到其生命值归零时触发；同时也识别支持格式的服务器击杀消息。仅消失、卸载或离开视野不会算作击杀。既能接收 Gale 攻击事件，也能跟踪从网络钩子实际发出的 C02 攻击，兼容其他客户端仅通过包攻击的情况。

**近期攻击后目标死亡是推断，并非服务器确认最后一击归属。**多人混战中，目标被别人补刀时仍可能触发。希望更严格时把 Detection 改为 `Server`：此时只接受支持的服务器消息，包括原版翻译组件的死亡消息及常见英文 `was killed/slain/shot/... by` 格式。自定义中文公告、特殊服务器计分协议、隐藏击杀公告等需要另加对应服务器的规则。

默认只记录玩家。Server 模式下，没有近期攻击记录的玩家击杀消息还要求受害者在玩家列表中；如果服务器先删除该玩家，再发公告，可能漏判。每个目标的死亡状态、生命值更新和消息会去重，避免同一死亡重复加级。

## Champions 性能设计

- 当前年份六张 300×300 原图的 GPU 基础像素数据约 2.06 MiB；三套都使用过后约 6.18 MiB。只在开启和切换年份时预载，渲染循环内不读取文件或创建动态贴图。
- MP3 离线转为 OGG，使用原版声音系统；没有额外播放器、每次击杀起线程或每帧音频解码。
- 空闲时不提交特效绘制；活跃时通常一次贴图绘制，过渡时最多两次。2024 五、六杀的光晕在同一次绘制中淡化外缘，柔化原始素材的方形截断，不额外创建纹理或使用后处理。
- 无粒子、模糊、后处理、离屏缓冲或每帧世界实体扫描。
- 每 tick 只检查最多 32 个近期目标；消息去重记录也有上限。
- 绘制使用缓存资源和基本数值计算，恢复所修改的深度、混合、透明度、纹理等 GL 状态。

实际 FPS 仍取决于显卡、分辨率、其他模组和场景，不能保证零开销。
