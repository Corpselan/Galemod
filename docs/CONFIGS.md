# 配置管理

Gale 和 Raven B4 两种 GUI 的右下角都有「配置」按钮，打开同一个配置管理页面。

## 使用

1. 打开任意 GUI，点击右下角「配置」。
2. 创建配置：在名称框中输入名称，点击「另存为」。这会保存当前模块状态，并启用这个命名配置。名称相同时会覆盖已有配置。
3. 加载配置：点击列表中的配置，再点击「加载所选」。列表超出范围时可在列表上滚动鼠标滚轮。
4. 点击「返回 GUI」或按 Esc 返回设置界面。修改模块开关、参数、绑定键、HUD 隐藏状态或好友后，约 1 秒自动保存到正在使用的配置，同时更新主配置。
5. 关闭任一 GUI、关闭配置页面或正常退出客户端时，会立即保存尚未写入的修改。下次启动会恢复上次保存的状态和正在使用的配置名称。

「保存当前」立即保存正在使用的配置；它不覆盖列表中另一个尚未加载的配置。

「自动保存（默认）」对应主配置，没有单独的命名文件。加载它后，后续修改只更新主配置。列表中的「使用中」标识表示当前自动保存的目标。

## 文件位置

路径相对于实际游戏目录（启动器使用独立版本目录时，以那个游戏目录为准）：

- 主配置：`galemod/config.json`
- 命名配置：`galemod/profiles/名称.json`

从别人那里获得兼容的 JSON 配置后，放进 `galemod/profiles/`，点击「刷新列表」即可选择加载。名称支持中文，长度最多 48 个字符；不能使用路径符号、Windows 保留名称或 `config`。

配置保留模块开关、参数、快捷键、按键模式、HUD 隐藏状态、好友，以及尚未注册的脚本模块设置。代码里使用 `isHide` 隐藏的模块或子选项，其设置仍会保存。
