GD656Killicon rendering port for GaleMod 1.8.9
Original author: Minecraft_GD656
Original project: gd656killicon, version 1.3.3-1.20.1-forge
The original README and mod metadata identify its license as MIT.
Rendering logic, built-in presets, textures and sounds are adapted from the user-provided source tree.
Gale supplies its own kill detection and 1.8.9 renderer; the upstream server protocol is not included.
